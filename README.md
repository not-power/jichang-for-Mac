# 鸡场 Mac

面向 Mihomo 配置管理的 macOS 原生应用。

## 系统要求

- macOS 15 或更高版本
- Apple Silicon

## 下载

[下载正式安装包](https://github.com/not-power/jichang-for-Mac/releases/latest)

0.11.2（构建 35）提供 DMG 和打包后的 `.app` ZIP。安装包未经过 Apple 公证。

## 源码

应用源码位于 `JichangMac/`，使用 Xcode 打开 `JichangMac.xcodeproj`。

仓库保留应用源码、项目文件及必要资源；正式安装包放在 GitHub Releases。
